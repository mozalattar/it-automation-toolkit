# Security policy

## Reporting a problem

If you find a security problem in any script here (for example, something that could delete the wrong files or be abused when run as root), please **do not open a public issue**.

Email **mozalattar@gmail.com** with:

- the script and version (commit or release),
- what happens and how to reproduce it,
- what you expected to happen.

You'll get a reply within 7 days. Once a fix is published, you're welcome to be credited in the changelog.

## Supported versions

Only the latest version on the `main` branch and the latest release receive fixes.

## Using the scripts safely

- Read a script before running it with `sudo` or as administrator.
- Use `--dry-run` on the macOS scripts to preview their changes.
- Download scripts only from this repository or its Releases page.
